# AWS Lex Translation Bot

## Project Description
A multilingual translation chatbot using Amazon Lex, AWS Lambda and Python.

## AWS Services
- Amazon Lex
- AWS Lambda
- AWS IAM
- Amazon CloudWatch

## Supported Languages
- Kannada
- French
- German
- Japanese
- Chinese
- Spanish
- Norwegian

## Translation API
MyMemory Translation API

## Working
1. User starts the conversation.
2. Bot asks for the target language.
3. User enters the language.
4. Bot asks for English text.
5. Lambda translates the text.
6. Lex displays the translated result.
